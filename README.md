## IronVision Tools

Practical software and AI tools for small businesses. Independent and self-funded, based in Edirne, Türkiye.
Everything is built and shipped by one person, Demir, working with terminal AI coding agents.

**Website:** [ironvisiontools.com](https://ironvisiontools.com)

### What we build

- **MoyMote** — control an external monitor's brightness, blue light and HDR from your Windows PC or from your phone. [moymote.com](https://moymote.com)
- **WhatsApp booking bot** — customers book an appointment by sending a message; no app to install. Built for barbers and salons.
- **Website showcase** — fast, static business sites built on a shared template set: [ironvisiontools.com/vitrin/vitrin-hub](https://ironvisiontools.com/vitrin/vitrin-hub/)
- **AgentOS** — the automation system that runs our own work: task board, watchdogs, scheduled jobs, backups.
- **Voice Chief** — a voice interface for terminal-based AI agents: speak to the agent, hear the answer back.

### How we work

Small, boring and real: static sites over frameworks, plain scripts over platforms. If a tool can't be explained to the person using it, it isn't finished.
